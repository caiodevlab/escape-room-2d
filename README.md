# Escape Room 2D - Escola

Jogo desenvolvido em **Godot 4.7.2** (GDScript) como projeto escolar de Escape Room 2D.

## Controles
- **WASD / Setas**: Movimentação do personagem nas 4 direções.
- **E**: Interagir com objetos, portas, chaves e enigmas.
- **ESC**: Pausar / Sair.

## Como Executar
1. Instale o **Godot Engine 4.x**.
2. Abra o projeto apontando para esta pasta (`/home/administrador/Documentos/projetos/escape-room-2d`).
3. Pressione **F5** para executar a cena principal (`scenes/main.tscn`).
